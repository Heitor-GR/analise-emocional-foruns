# Emotional Analysis of Academic Forums (Affective Computing)

This project applies Emotional Artificial Intelligence concepts to measure emotional trends in student texts and interactions within academic forums and educational platforms.

## What the code does
It utilizes Natural Language Processing (NLP) with the Hugging Face `pysentimiento/bert-pt-emotion` model to classify messages into emotional categories (such as joy, anger, sadness, or surprise).

## How to run locally
1. Install the required libraries: `pip install transformers torch pandas`
2. Run the script: `emotionClassificator.py`

*Project developed as part of practical explorations in AI and NLP.*


# Análise Emocional de Fóruns Acadêmicos (Affective Computing)

Este projeto aplica conceitos de Inteligência Artificial Emocional para medir tendências emocionais em textos e interações de estudantes em fóruns e plataformas educacionais.

## O que o código faz
Utiliza Processamento de Linguagem Natural (NLP) com o modelo `pysentimiento/bert-pt-emotion` da Hugging Face para classificar mensagens em categorias emocionais (como alegria, raiva, tristeza ou surpresa).

## Como rodar localmente
1. Instale as bibliotecas: `pip install transformers torch pandas`
2. Execute o script: `emotionClassificator.py`

*Projeto desenvolvido como parte das explorações práticas em IA e NLP.*
