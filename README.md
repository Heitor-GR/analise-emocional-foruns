[PT-BR] Pipeline automatizada em Python para análise de sentimento e extração estatística de estados afetivos em fóruns acadêmicos e ambientes de comunidade, utilizando modelos de estado da arte (*Transformers*) ajustados para o português.

[EN] An automated Python pipeline for sentiment analysis and statistical extraction of affective states in academic and community forums, utilizing state-of-the-art *Transformer* models fine-tuned for Portuguese.

---

## 🎯 Objetivo / Objective

* **PT-BR:** Mapear o clima emocional e a satisfação de usuários/estudantes em interações de fórum, identificando focos de insatisfação, desespero ou engajamento para tomada de decisão baseada em dados em tempo real.
* **EN:** Map emotional climate and user/student satisfaction in forum interactions, identifying pain points, churn risk, or engagement for data-driven real-time decision-making.

---

## 🛠️ Stack Tecnológica / Tech Stack

* **Language:** Python 3.12+
* **NLP Model:** `pysentimiento/robertuito-sentiment-pt` (RoBERTa architecture for Portuguese NLP)
* **Data Manipulation:** Pandas
* **Visualization:** Seaborn & Matplotlib
* **Version Control:** Git & GitHub

---

## 📈 Resultados & Visualizações / Results & Visualizations

A pipeline processa as mensagens, gera relatórios estatísticos em formato tabular no terminal e exporta automaticamente gráficos de distribuição em alta resolução.
